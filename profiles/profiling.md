# Профилирование памяти (pprof)

В проекте есть отдельный HTTP-сервер для pprof, помимо основного HTTP API.

## Как включить pprof

pprof-сервер запускается только при условии, что для него задан адрес.

### Флаги / переменные окружения

- Адрес pprof-сервера:
    - флаг: `-pprof`
    - переменная окружения: `PPROF_ADDR`
    - по умолчанию: пусто (pprof выключен)

Пример запуска:

```bash
go run ./cmd/server -a localhost:8080 -pprof localhost:6060
```

После запуска доступны ручки для профилирования, например:

- Индекс: `http://localhost:6060/debug/pprof/`
- CPU профиль: `http://localhost:6060/debug/pprof/profile?seconds=30`
- Heap профиль: `http://localhost:6060/debug/pprof/heap`

## Генерация нагрузки

Для генерации нагрузки можно использовать утилиту `hey`. Она простая и не требует конфигов в отдельных файлах.

### Пример нагрузки (обновление метрик)

```bash
hey -z 60s -c 20 -m POST -T "application/json" \
  -d '[{"id":"m1","type":"gauge","value":123.45},{"id":"m2","type":"counter","delta":1}]' \
  http://localhost:8080/updates
```
#### Назначение флагов:

- -z 60s - длительность теста: запросы будут генерироваться 60 секунд;
- -c 20 - конкурентность: одновременно выполняется до 20 запросов;
- -m POST - HTTP-метод: запросы отправляются методом POST;
- -T "application/json" - заголовок Content-Type: тело запроса в формате JSON;
- -d '...' - тело запроса: данные, которые отправляются в каждом POST-запросе.


## Примерный сценарий оптимизации использования памяти с помощью профилирования

1. Создать директорию:

```
mkdir -p profiles
```

2. Запустить сервер с включенным pprof:

```
go run ./cmd/server/ --pprof=localhost:6060
```

3. В другом терминале запустить имитацию нагрузки:

```
hey -z 60s -c 20 -m POST -T "application/json" -d '[{"id":"m1","type":"gauge","value":123.45},{"id":"m2","type":"counter","delta":1}]' http://localhost:8080/updates
```

4. В третьем терминале снять базовый профиль памяти:

```
curl -sS localhost:6060/debug/pprof/heap -o profiles/base.pprof
```

5. Проанализировать базовый профиль памяти:

```
go tool pprof -top -sample_index=alloc_space profiles/base.pprof
```

Для интерактивного UI в браузере следует заменить флаг `-top` на `-http=:9091`.

6. Внести изменения в код для оптимизации использования памяти.

7. Повторить предыдущие шаги, но сохранить профиль как `profiles/result.pprof`.

8. Сравнить профили:

```
go tool pprof -top -sample_index=alloc_space -diff_base=profiles/base.pprof profiles/result.pprof
```
В выводе `-diff_base` отрицательные значения означают снижение потребления памяти.

Здесь также можно заменить флаг `-top` на `-http=:9091` для интерактивного UI в браузере.
